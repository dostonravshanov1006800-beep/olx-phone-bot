# OLX Phone Hunter 📱

Telegram-бот, который 24/7 сам ищет на OLX.uz (раздел «Мобильные телефоны»)
выгодные смартфоны **2021 года и новее** и присылает их с фото, ценой,
сравнением с рынком и ссылкой. Работает у всех, без админ-панели.

## Как это работает

GitHub Actions каждые 5 минут запускает один цикл `python bot/main.py`:

1. Обрабатываются команды пользователей (`getUpdates`).
2. Скачивается выдача OLX.uz (прямой запрос, при блоке IP — через Jina Reader).
3. Отбираются модели 2021+ (`models.yaml`), мусор (чехлы/запчасти/планшеты) — нет.
4. Цена сверяется с медианной рыночной ценой группы (модель+память+состояние,
   очистка выбросов IQR, история за 30 дней). Выгодным считается скидка
   ≥15% к рынку, 🔥 — ≥25%, подозрительно дёшево (<40% рынка) — блокируется.
5. Карточка (фото + подпись + кнопка «Открыть на OLX») уходит всем, кто
   включил `/auto_search`. Повторно — только если цена снизилась (📉).
6. Состояние коммитится в репозиторий (`data/`), поэтому дубликатов нет
   даже после перезапуска, а первый запуск (baseline) не заваливает чат.

## Команды

| Команда | Действие |
|---|---|
| `/start` | «Нажми /auto_search, чтобы включить авто-поиск» |
| `/auto_search` (или `/auto search`) | включить/выключить авто-поиск |

Других команд нет — это сделано специально.

## Секреты (Settings → Secrets and variables → Actions)

| Секрет | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `ADMIN_CHAT_ID` | (необязательно) куда прислать один алерт, если OLX заблокирует бота |

## Запуск / обновление

- Автоматически: workflow `bot` уже активен, cron каждые 5 минут.
- Вручную: Actions → **bot** → **Run workflow**.
- Логи: Actions → bot → последний запуск.
- Список моделей: правь `models.yaml` (regex-диапазоны подхватывают новые
  поколения сами) → push.

## Важные нюансы GitHub-хостинга

- Коммиты состояния каждые 5 минут держат репозиторий активным (GitHub
  отключает cron в репозиториях без активности дольше 60 дней).
- OLX.uz блокирует IP дата-центров (403). Поэтому в `bot/olx.py` сначала
  идёт прямой запрос, а при блоке — чтение через r.jina.ai (публичный reader).
- Если OLX начнёт блокировать стабильно — рабочий вариант свой VPS:
  `python bot/main.py --loop` (интервал `SCAN_INTERVAL_SEC`, по умолчанию 120 c)
  или Docker:

```bash
cp .env.example .env   # вписать BOT_TOKEN
docker compose up -d --build
```

## Файлы

```
bot/main.py       цикл: команды -> скан -> рассылка -> коммит состояния
bot/olx.py        получение выдачи OLX.uz (прямой + Jina), парсинг карточек
bot/models.py     whitelist моделей 2021+, извлечение память/состояние
bot/pricing.py    медианы, IQR, Deal Score, курс USD (кэш на сутки)
bot/telegram.py   Bot API с лимитом ~1 msg/сек и обработкой 429
bot/state.py      JSON-состояние в data/ (дедуп, история цен, подписки)
models.yaml       список моделей и фильтры (правится без кода)
```
